# DOCUMENTS

This folder contains documents, transcripts, dialogues, scripts, and the plot of MARIN★. The documents in this folder are protected by copyright. This folder serves as a library for the story of MARIN★.

Expect tons of updates to the files present in this folder, as dialogues, transcripts, and lines change. Files will be renamed depending on their version, label, focus, and purpose.

There are two file types available in this folder. `docx.` and `.txt` files are available to download. We recommend downloading the `docx.` file if you want the document locally. The `.txt` file is designed for the document to be viewable on GitHub.

To install the `docx.` files present in this folder, click on the file and click `View raw`, which should automatically download the file. You can find your file in the `Downloads` directory in your File Explorer.
